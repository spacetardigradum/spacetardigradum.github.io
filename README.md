# Wizard Hut

A lightweight static website for private one-to-one consulting conversations. The first version lists four conversation areas and uses email for booking requests. Online scheduling and payment are not integrated yet.

- Session length: 60 minutes
- Price: USD 50
- Contact: pekeott@gmail.com
- Public site: https://spacetardigradum.github.io/wizardshut/
- Pages project path: `wizardshut/` in the user-site repository.

The site has no runtime data APIs or third-party JavaScript dependencies.
